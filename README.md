# ВИВА — ногтевая студия в Адлере

Статический сайт без зависимостей. Готовые файлы находятся в `dist/`.

Локальный просмотр: `python3 -m http.server 8081 --directory dist`.

## Что работает

- Подбор маникюра по четырём настроениям: палитра, фотография и сообщение студии.
- Галерея настоящих работ: фильтр, раскрытие, просмотр, клавиатурная навигация и скачивание референса.
- Три категории услуг с ценами и подготовленными сообщениями для записи.
- Онлайн-запись через действующий Yclients студии, телефон, WhatsApp, Telegram, ВКонтакте и маршрут.
- Адаптивное меню, доступные вкладки, видимый фокус и поддержка уменьшенного движения.

Фотографии работ, прайс и телефон взяты из карточки студии на Яндекс Картах. В `SOURCES.json` указаны ссылки на фотографии. Шесть отзывов сверены с карточкой 22 ноября 2026 года и снабжены ссылками на оригиналы. Монограмму, адрес для сайта, сведения о стаже мастеров и условия акции предоставила студия. Запись и общение проходят в сервисах студии.

Хостинг настроен в `.openai/hosting.json`.

SEO-настройки и цены: `content/seo.json`. Генерация: `node scripts/prepare-seo.mjs`. Проверка: `python3 scripts/check-seo.py`. Подробности и шаги для индексации находятся в `SEO.md`.
