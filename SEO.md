# SEO ВИВА

Внедрено 17 ноября 2026 года для https://viva-nails-adler.maisdev.chatgpt.site/.

Основные поисковые темы: маникюр в Адлере, педикюр в Адлере, ногтевая студия ВИВА, маникюр на Ульянова, наращивание ногтей в Адлере. Формулировки встроены в видимый текст без скрытых блоков и повторов.

В HTML находятся единственный H1, title и description, canonical, Open Graph, карточка предпросмотра для соцсетей, полный каталог из 16 услуг и ответы перед визитом. JSON-LD описывает NailSalon, адрес, телефон, график, координаты, запись и каталог услуг. Рейтинг Яндекс Карт остаётся в видимом блоке отзывов; в разметку собственных рейтингов он не включён.

Есть robots.txt и sitemap.xml с одной реальной страницей. Адрес в sitemap, canonical и JSON-LD одинаковый. Фотографии имеют адаптивные WebP-версии, размеры и alt; главное изображение получает приоритет загрузки. JPEG-оригиналы сохранены для скачивания.

## Обновление

Метаданные, основной адрес сайта, цены и сведения о студии хранятся в `content/seo.json`. После изменений:

```sh
node scripts/prepare-seo.mjs
python3 scripts/check-seo.py
node --check dist/app.js
```

Если меняются фотографии, дополнительно запустить `python3 scripts/prepare-images.py` (нужен Pillow), затем `node scripts/prepare-seo.mjs`. Поле `modified` менять при реальном изменении страницы, а не при каждом запуске генератора.

## Что требуется для индексации

На момент проверки сайт доступен только владельцу. Анонимный запрос возвращает HTTP 401. robots.txt и метаданные не обходят авторизацию: перед индексацией владелец должен явно включить публичный доступ.

После этого проверить анонимный HTTP 200 для главной, robots.txt, sitemap.xml и изображений; отсутствие запрета индексации в HTTP-заголовках; корректный ответ для несуществующего URL. Затем подтвердить права в Яндекс Вебмастере и Google Search Console, отправить sitemap.xml и запросить переобход. Эти действия пока не выполнены: учётные записи и подтверждение прав не предоставлены.

При подключении собственного домена сначала выбрать основной адрес, настроить постоянный редирект с прежнего домена и обновить `url` в конфигурации. В карточке Яндекс Бизнеса указать этот основной адрес сайта. Доступ к аккаунтам студии и изменение карточки требуют участия владельца.

Позиции и сроки попадания в поиск не гарантируются. Текущая проверка подтверждает локальную корректность кода и публикацию; внешние валидаторы и роботы не могут прочитать закрытый сайт.
