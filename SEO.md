# SEO ВИВА

Внедрено 17 ноября 2026 года для https://kissdepth.github.io/viva-nail-atelier/.

Основные поисковые темы: маникюр в Адлере, педикюр в Адлере, ногтевая студия ВИВА, маникюр на Ульянова, наращивание ногтей в Адлере. Формулировки встроены в видимый текст без скрытых блоков и повторов.

В HTML находятся единственный H1, title и description, canonical, Open Graph, карточка предпросмотра для соцсетей, полный каталог услуг и акций и ответы перед визитом. JSON-LD описывает NailSalon, адрес, телефон, график, координаты, запись и каталог услуг. Рейтинг Яндекс Карт остаётся в видимом блоке отзывов; в разметку собственных рейтингов он не включён.

Есть robots.txt и sitemap.xml с одной реальной страницей. Адрес в sitemap, canonical и JSON-LD одинаковый. Фотографии имеют адаптивные WebP-версии, размеры и alt; главное изображение получает приоритет загрузки. JPEG-оригиналы сохранены для скачивания.

## Обновление

Метаданные, основной адрес сайта, цены и сведения о студии хранятся в `content/seo.json`. После изменений:

```sh
node scripts/prepare-seo.mjs
python3 scripts/check-seo.py
node --check dist/app.js
```

Если меняются фотографии, дополнительно запустить `python3 scripts/prepare-images.py` (нужен Pillow), затем `node scripts/prepare-seo.mjs`. Поле `modified` менять при реальном изменении страницы, а не при каждом запуске генератора.

## Публикация на GitHub Pages

Основной адрес страницы — https://kissdepth.github.io/viva-nail-atelier/. При смене домена обновите поле `url` в `content/seo.json` и заново запустите генерацию.
